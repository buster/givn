givn Change lifecycle — proposal to archive

One lane per artifact. Blue steps create what the grey card names; yellow cards are the checks applied to that lane. Every check blocks except those tagged advisory. An optional ideation flow — domain-driven event storming — can precede phase 1; it produces no chain artifact. Between gates the order is advisory only — enforcement concentrates at the three chokepoints listed below.

Semantic duplicate pipeline (inside “check review”)

E5 · intfloat/multilingual-e5-large recall — cosine over embedded scenarios vs delta candidates similarity ≥ 0.95 admits a candidate
BGE · rozgo/bge-reranker-v2-m3 cross-encoder evidence on the top-5 pool symmetric logit ≥ 3.0 ⇒ BGE_RECOMMENDED
NLI · mDeBERTa-v3-base-xnli entailment evidence over the same pool symmetric entailment ≥ 0.5 ⇒ NLI_RECOMMENDED

Evidence never replaces the E5 gate and never auto-classifies: recommendations intersect, but the blocking decision requires human classification in semantic-review.md. Pair budget default 2048 (GIVN_SPEC_MAX_RERANK_PAIRS), 512-token serialization cap per stage; BGE/NLI are skipped when the E5 pool is empty; a feature-free build reports retrieval unavailable instead of passing silently.
