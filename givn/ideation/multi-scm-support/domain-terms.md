# Domain terms: multi-scm-support

Terms as they crystallize. Candidates are merged into the durable term list
at handoff by user decision.

| Term | Candidate definition | Collision or note |
|---|---|---|
| SCM backend | The concrete version-control system givn talks to in a project: Git or Fossil. | Anti-term: provider, driver (implementation words). Collision check 2026-09-18: `rg -ci --count-matches "SCM backend" docs/arc42/12-glossary.md` → 3; `rg -ci --count-matches "SCM backend" givn docs assets --glob '!**/archive/**'` → 21 files, 33 hits; no colliding meaning found. |
| Revision | One immutable recorded state of the project in the active SCM. Git: commit hash. Fossil: check-in hash. | Collides with Git "commit" and Fossil "check-in"; the domain needs one neutral term. Collision check 2026-09-18: `rg -ci --count-matches "revision" docs/arc42/12-glossary.md` → 19; `rg -ci --count-matches "revision" givn docs assets --glob '!**/archive/**'` → 55 files, 336 hits; no colliding meaning found. |
| Checkout | The working directory givn operates in, as seen by the active SCM. Git calls it a worktree; Fossil calls it a checkout. | Collides with Git "worktree"; the domain currently says worktree. Collision check 2026-09-18: `rg -ci --count-matches "checkout" docs/arc42/12-glossary.md` → 3; `rg -ci --count-matches "checkout" givn docs assets --glob '!**/archive/**'` → 53 files, 143 hits; no colliding meaning found. |
| Repository root | The directory the SCM considers the project boundary. Git: worktree top level. Fossil: the directory holding `.fslckout`/`_FOSSIL_`; the repository file itself lives elsewhere. | TC-32 currently equates this with the Git worktree top level. |
| Clean state | The state in which the SCM reports no changes that would enter the next revision. | Git and Fossil disagree on whether untracked/`EXTRA` files count. Collision check 2026-09-18: `rg -ci --count-matches "clean state" docs/arc42/12-glossary.md` → 1; `rg -ci --count-matches "clean state" givn docs assets --glob '!**/archive/**'` → 7 files, 7 hits; no colliding meaning found. |
| Candidate revision | The revision that publishes the merged archive before verification. | Currently `candidate_commit` in the receipt. Collision check 2026-09-18: `rg -ci --count-matches "candidate revision" docs/arc42/12-glossary.md` → 2; `rg -ci --count-matches "candidate revision" givn docs assets --glob '!**/archive/**'` → 18 files, 49 hits; no colliding meaning found. |
| Tested revision | The revision against which every verification scope passed. | Currently `tested_commit` in the receipt. Collision check 2026-09-18: `rg -ci --count-matches "tested revision" docs/arc42/12-glossary.md` → 4; `rg -ci --count-matches "tested revision" givn docs assets --glob '!**/archive/**'` → 10 files, 23 hits; no colliding meaning found. |
| Revision binding | The receipt property that the tested revision is the published candidate revision. | Currently expressed as `HEAD == tested_commit`. Collision check 2026-09-18: `rg -ci --count-matches "revision binding" docs/arc42/12-glossary.md` → 1; `rg -ci --count-matches "revision binding" givn docs assets --glob '!**/archive/**'` → 7 files, 8 hits; no colliding meaning found. |
| Hook | An extension point of the active SCM. Git offers `commit-msg`; Fossil 2.26 offers only `before-commit` and `after-receive`. | Collides with givn's own artifact `post` hooks; never use the bare word without the qualifier. |
| Index / staging area | A Git-only concept: the intermediate area that `git add` fills and `git commit` consumes. Fossil commits named paths directly. | The domain must not require an index; "publish a subset" is the portable concept. |
| Upgrade revision / plan revision | The two automatic revisions of a managed upgrade, in neutral vocabulary. | Collides with the glossary's "Upgrade Commit A" / "Migration Commit B" and the `upgrade_commit` metadata key — Q10. Collision check 2026-09-18: `rg -ci --count-matches "upgrade revision" docs/arc42/12-glossary.md` → 2; `rg -ci --count-matches "upgrade revision" givn docs assets --glob '!**/archive/**'` → 14 files, 30 hits; no colliding meaning found. Collision check 2026-09-18: `rg -ci --count-matches "plan revision" docs/arc42/12-glossary.md` → 1; `rg -ci --count-matches "plan revision" givn docs assets --glob '!**/archive/**'` → 12 files, 23 hits; no colliding meaning found. |
| Check-in (Fossil) | One immutable recorded revision in Fossil. | Unrelated to givn's `givn check` commands and mandatory checks; never shorten either to "check". |

Q10 resolved 2026-09-14: the neutral terms (`revision`, `checkout`, `clean
state`, `candidate revision`, `tested revision`, `revision binding`, `upgrade
revision`, `plan revision`) were merged into the durable term list
(`docs/arc42/12-glossary.md`); per-SCM terms stay in the backend seam.
