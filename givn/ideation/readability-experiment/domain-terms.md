Status meanings: `candidate` has a definition and first use; `confirmed`
requires the user's verified name plus the full term introduction test;
`rejected` keeps the definition and the rejection reason.

Confirmed names (user, 2026-10-19): Readability experiment, Project review,
Candidate finding, Selected finding, Experiment scope, Fix commit.
