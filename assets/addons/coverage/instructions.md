# Instruction: coverage

Produce the project coverage report by running the configured measurement
script and merging its E2E and non-E2E reports.

## What this artifact is

The coverage addon is an archive-level gate. It produces the merged Cobertura
report configured by `coverage.output_path` and updates the README from that
report:

- The two badges (line and branch coverage) go directly after the README
  title, and both link to the merged `coverage.output_path` — never only to
  the non-E2E report.
- The `## Coverage` section carries the merged line/branch totals, the merged
  report link, and the exact measurement and merge commands.
- The badges and the summary live in the managed
  `<!-- givn:begin:coverage-badge -->` / `<!-- givn:begin:coverage -->`
  marker blocks: never hand-edit them — the gate rewrites both from the merged
  report.

## How to run

1. Ensure `tasks.md` is complete (all checkboxes checked).
2. Run `givn archive` — this executes `coverage.measure_command` and then
   `coverage.merge_command` from `givn/commands.yaml`.

The measurement and merge scripts receive `GIVN_FEATURES` and the configured
coverage paths through environment variables. They should:

1. The measurement command writes the non-E2E and E2E Cobertura files.
2. The merge command combines those files into `coverage.output_path`.
3. Exit non-zero when either command or report is invalid.
4. Let givn read the merged report and update the README.

## Coverage regression policy

Coverage is reviewed for completeness of gap classification, not against a
percentage threshold. The README values are descriptive output from the merged
report.

## Baseline maintenance

The project-level report is updated by running the two configured scripts
without a change context. The merged report lives at `coverage.output_path`.

## README coverage example

Place the two generated badges directly after the README title. Both badges
link to the merged `coverage.output_path`, never only to the non-E2E report.

```markdown
# <project name>

<!-- givn:begin:coverage-badge -->
[![Line Coverage: 77.8%](https://img.shields.io/badge/line%20coverage-77.8%25-brightgreen)](coverage/cobertura-coverage.xml)
[![Branch Coverage: 64.2%](https://img.shields.io/badge/branch%20coverage-64.2%25-brightgreen)](coverage/cobertura-coverage.xml)
<!-- givn:end:coverage-badge -->
```

Keep the `## Coverage` section below the badges with the merged totals:

```markdown
## Coverage

The merged coverage report combines the non-E2E and E2E runs. It covers
`583/749` lines (`77.8%`) and `321/500` branches (`64.2%`).

Merged report: [coverage/cobertura-coverage.xml](coverage/cobertura-coverage.xml)

```sh
./measure-coverage.sh
./merge-coverages.sh
```
```

The managed `<!-- givn:begin:coverage-badge -->` and
`<!-- givn:begin:coverage -->` blocks are generated by the archive gate -
verify them after the run, never hand-edit them. Replace the example values,
paths, and commands with this project's configured ones.
