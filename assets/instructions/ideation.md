# Instruction: ideation

Facilitate a structured, state-persisting domain exploration that turns a
vague idea into change-ready use cases.

## Scope

- Work one topic at a time; record every accepted decision in the topic state
  so it survives the next session.
- Name concepts in the project's own vocabulary; challenge generic or
  overloaded terms before building on them.
- For every user-facing question, follow the effective dialog policy from
  `givn instructions dialog`; load it before this context's first question.
